개인정보처리방침

시행일: 2026년 10월 6일

1. 앱의 성격

Claude Calendar Sync(이하 "앱")는 앱 소유자 개인이 자신의 일정을 Google 캘린더로 동기화하기 위해 만든 도구입니다. 불특정 다수에게 제공되는 서비스가 아닙니다.

2. 접근하는 Google 사용자 데이터

앱은 Google Calendar API 의 https://www.googleapis.com/auth/calendar 범위를 사용해 사용자 본인 계정의 캘린더 목록과 일정을 읽고, 일정을 생성·수정·삭제합니다.

3. 데이터의 이용

캘린더 데이터는 오직 사용자가 지정한 캘린더에 일정을 동기화하는 목적에만 사용됩니다. 광고, 프로파일링, 분석, 판매 등 다른 목적으로 이용하지 않습니다.

4. 데이터의 저장과 공유

Google 로부터 받은 OAuth 토큰은 사용자 본인이 관리하는 컴퓨터에만 저장되며, 외부 서버로 전송되지 않습니다. 캘린더 데이터는 제3자와 공유되지 않습니다.

5. 데이터 보유와 삭제

사용자는 언제든지 Google 계정 권한 페이지에서 앱의 접근 권한을 철회할 수 있으며, 철회 즉시 앱은 더 이상 데이터에 접근할 수 없습니다. 저장된 토큰은 사용자가 로컬에서 직접 삭제합니다.

6. Google API 서비스 사용자 데이터 정책 준수

앱의 Google API 로부터 받은 정보의 사용과 전송은 Google API Services User Data Policy(제한적 사용 요건 포함)를 준수합니다.
